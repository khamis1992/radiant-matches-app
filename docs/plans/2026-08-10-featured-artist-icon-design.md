# Featured Artist Icon

## Purpose

Create a proprietary GLAM icon for the "Top Rated Artists" section that remains recognizable at 24–48 px and does not resemble a generic icon-library glyph.

## Visual Direction

- Abstract feminine profile built from a clean natural curve.
- Makeup brush integrated into the silhouette to communicate the artist role.
- One four-point star to communicate featured status.
- GLAM Ink, Rose, and Blush only.
- No enclosing circle, crown, text, logo recreation, or extra decoration.
- Transparent background and compact square crop for UI use.

## Integration

The final PNG replaces the former crown artwork in the Home page section header while retaining the existing accessible alt text and layout dimensions.
