# Home top-rated artists header

## Goal

Match the supplied editorial section-header reference on mobile while removing every star element.

## Design

- Use a borderless editorial row that flows directly into the artist cards.
- Keep the animated artist icon inside one quiet 48px soft surface.
- Pair the title with a concise trust message rather than decorative marks.
- Present “See All” as text plus one 44px rose action circle.
- Replace the static underline with a functional progress indicator tied to horizontal card scrolling.
- Snap artist cards into place while leaving the next card visible as a swipe affordance.
- Preserve only the face and brush layers in the Lottie scene; remove the star asset and layer entirely.
