# Shops Hero Video

## Creative direction

Create an eight-second, silent, seamlessly looping cinematic product tableau for the Shops page. The frame features premium beauty products—lipstick, skincare serum, perfume, and a makeup brush—on a clean porcelain vanity with restrained blush accents. Camera motion is a slow lateral dolly with subtle product rotation and soft moving reflections. No people, generated typography, logos, glitter, or decorative stars.

## UI placement

The 16:9 video sits below the compact navigation row and above the Shops heading. It uses rounded corners, a porcelain poster/fallback, muted autoplay, inline playback, and intersection-based pause/play behavior. Page text remains outside the media so it stays accessible and localized.

## Brand constraints

White/porcelain dominates, ink provides depth, and pink stays below ten percent as a controlled accent. The video has no permanent color filter and uses no unapproved decorative elements.
