# Seller Profile Redesign

## Goal

Bring the seller profile reached through the artist route into the same visual system as the GLAM home and shops experiences while preserving the existing data, chat, favorite, sharing, cart, and review flows.

## Design

- Use the approved shops video as the single premium hero surface.
- Place navigation, sharing, favorite, verification, shop name, and location directly over the hero.
- Overlap one porcelain identity card containing the shop mark, description, stats, and the primary contact action.
- Present delivery, authenticity, and response benefits as compact neutral trust cards.
- Use a sticky two-option ink tab control for products and reviews.
- Render product cards and empty states with GLAM token colors only; reserve rose for accents and ink for primary actions.
- Keep the global bottom navigation and provide sufficient bottom spacing for safe-area use.

## Accessibility

- All icon-only actions have accessible labels and pressed state where relevant.
- Primary actions use white on GLAM Ink.
- Text on light surfaces uses Ink, Secondary, or Muted tokens.
- The layout is mobile-first, avoids horizontal overflow, and respects safe-area spacing.
