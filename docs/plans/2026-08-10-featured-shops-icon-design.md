# Featured Shops Icon

## Purpose

Replace the generic shops mark with a proprietary GLAM icon and rename the Home section to "Featured Shops" / «المتاجر المميزة».

## Visual Direction

- Compact beauty boutique storefront with a scalloped awning.
- Cosmetic silhouettes in the windows communicate the marketplace category.
- One four-point GLAM star communicates featured status.
- GLAM Ink, Rose, Blush, and white only.
- No enclosing circle, crown, text, logo recreation, or extra decoration.
- Transparent square asset optimized for 24–48 px UI use.

## Integration

The final transparent PNG replaces the previous shops artwork in the Home section header while preserving the existing navigation action and accessible label.
